# 内存与会话 🧠

OpenClaw 提供了强大的记忆系统和会话管理功能。

## 会话管理

### 什么是会话？

会话是用户与 AI 助手之间的一次完整对话。OpenClaw 为每个发送者维护独立的会话。

### 会话特性

- **独立会话**：每个用户/群组拥有独立会话
- **上下文保持**：自动维护对话上下文
- **会话重置**：支持 `/reset` 命令重置会话

## 记忆系统

### 两阶段记忆整合

OpenClaw 采用创新的两阶段记忆整合机制：

```
第一阶段：工作记忆
  └── 当前对话上下文
  └── 活跃信息

第二阶段：长期记忆
  └── 重要信息提取
  └── 记忆整合
```

### 记忆操作

| 操作 | 说明 |
|------|------|
| 记住 | 保存重要信息到长期记忆 |
| 遗忘 | 清理不相关的信息 |
| 检索 | 从记忆中获取相关信息 |

## 上下文管理

### 上下文窗口

OpenClaw 自动管理上下文长度：

- **自动压缩**：当上下文接近限制时自动压缩
- **智能摘要**：保留重要信息，压缩次要内容
- **动态调整**：根据模型限制调整上下文

### 上下文配置

```json5
{
  memory: {
    maxContext: 128000, // 最大上下文 token 数
    compressionThreshold: 100000, // 压缩阈值
  },
}
```

## 会话配置

### 每个发送者的会话

```json5
{
  sessions: {
    perSender: true, // 每个发送者独立会话
    expireAfter: "7d", // 会话过期时间
  },
}
```

### 群组会话

```json5
{
  sessions: {
    group: {
      shared: false, // 群组内不共享会话
      mentionRequired: true, // 需要 @机器人
    },
  },
}
```

## 记忆存储

### 存储位置

记忆数据存储在 `~/.openclaw/memory/` 目录：

```
~/.openclaw/memory/
├── sessions/      # 会话数据
├── longterm/      # 长期记忆
└── cache/         # 缓存
```

### 数据格式

会话数据采用 JSON 格式存储：

```json
{
  "sessionId": "user_123456",
  "messages": [...],
  "createdAt": "2024-01-01T00:00:00Z",
  "updatedAt": "2024-01-01T12:00:00Z",
}
```

## 最佳实践

1. **定期清理**：定期清理旧会话以节省空间
2. **重要信息标记**：将重要信息标记以便长期记忆
3. **上下文优化**：避免过长的单次对话
