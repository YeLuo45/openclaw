# 领域层 (Domain)

本目录存放**领域概念与模型**的文档，不直接存放会话原文或配置数据。

## 用途

- **术语表**：项目或业务中的关键术语定义（如「记忆系统」「归档」「会话」等）。
- **实体与值对象**：核心概念的说明（如 Conversation、ArchiveEntry、Topic 等），便于应用层与基础设施层命名一致。
- **领域规则**：与记忆、归档、检索相关的简单规则描述。

## 文件约定

- 仅 Markdown 文档（`.md`）。
- 建议：`glossary.md`（术语表）、`entities.md`（实体说明）、`rules.md`（可选，领域规则）。

## 数据存放

领域层**不存放**具体会话内容或配置；实际归档数据在 **infrastructure/** 下。
