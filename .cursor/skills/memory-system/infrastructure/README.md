# 基础设施层 (Infrastructure)

本目录存放**实际归档数据**：会话原文、按主题分类的片段与配置等。

## 子目录约定

| 子目录 | 用途 |
|--------|------|
| **conversations/** | 按日期或会话 ID 的完整/摘要归档，如 `2026-02-12-session-a.md` |
| **topics/** | 按主题或功能模块分类的片段、结论、配置，如 `qq-channel.md`、`gateway-config.md` |

## 文件格式

- 推荐 Markdown（`.md`），便于阅读与检索。
- 可选 JSON（`.json`）用于结构化索引或元数据。
- 文件内容应包含：日期、来源简述（如「Cursor 会话」）、正文。

## 与其它层的关系

- **domain/**：不依赖；命名可参考领域术语。  
- **application/**：应用层可在此目录创建/追加文件，并可在 `application/` 中维护指向本目录的索引。
